# Aroquix Privacy Policy

This folder is ready for GitHub Pages.

## Publish with GitHub Pages

1. Create a new GitHub repository, for example: `aroquix-privacy`.
2. Upload `index.html` to the root of the repository.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and the `/ (root)` folder.
6. Save and wait for GitHub Pages to publish.

Your public URL will normally look like:

`https://YOUR-GITHUB-USERNAME.github.io/aroquix-privacy/`

Use that public URL in Google Play Console under the Privacy Policy field.
